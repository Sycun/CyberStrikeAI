# 批量任务管理

2026-11-14，任务管理恢复 v1.8.0 的批量队列逻辑及界面，撤回后续目标任务和统一列表改造。深度测评继续保持移除，上游 PR #383 保持关闭；其他模块的后续修复保留。

## 使用方式

1. 打开「任务管理 → 新建任务」，每行填写一项任务，可设置标题、项目、角色、代理模式、工具审批和并发数。
2. 选择手动执行或 Cron 定时执行；是否立即执行由创建窗口中的选项决定。
3. 队列列表支持状态筛选、关键字搜索和分页。默认每页 10 个队列，可切换为 20、50 或 100。
4. 点击队列打开详情窗口，查看子任务状态、结果和对话；按队列状态提供开始、暂停、继续、重新运行、添加及编辑子任务等操作。

这里执行的是用户提供的任务清单，不再提供独立的目标规划、验收、预算或补充方向控制器。

## 数据与兼容

- 保留原有批量任务、定时配置、子任务结果和执行会话；继续使用 `/api/batch-tasks` 接口。
- 撤回 `/api/tasks` 统一列表及 `/api/long-tasks` 接口、相关权限资源和运行引擎。
- 回退不删除已存在的目标任务或深度测评历史表，也不把它们转成批量队列，不继续执行其中的任务。需要读取这部分历史时，可使用对应历史版本和数据库备份。
- 本次只修改开发版源码并同步个人仓库；运行环境需单独更新，源码回退不等于已经部署。
